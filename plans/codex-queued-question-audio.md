Blocking requests complete only after answers; async requests return acceptance immediately. Use separate exact matchers so rejected async calls never announce a queued question. Hook stdin has session_id, transcript_path, tool_name, tool_input and optional agent_id. Confirm native delivery in an isolated fake-provider run. Resolve first transcript metadata under CODEX_HOME and require a matching root cli/vscode conversation; helpers, unknown/ambiguous identities, unrelated tools and permission reviews stay silent. Prefer actual question text over short UI headers or task titles. Join up to three question prompts into one sentence, omit options and secret questions, bound spoken text, strip control characters and preserve literal shell-looking text through JSON stdin. No cloud summarization. Missing/malformed questions stay silent. Existing completion-title audio remains intact.
