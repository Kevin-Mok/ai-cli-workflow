# Design Skill Stack Daily Sync ExecPlan

## Purpose and observable outcome

Make the requested public design stack reproducible on another PC with
`chezmoi apply` and refresh its upstream skill content daily at 05:00 local
time. The timer updates skills only; it must never authenticate an account,
generate media, spend credits, or silently upgrade the Higgsfield CLI.

## Current context, scope, and protected state

- Protected pre-existing dirty state: `aliases/key_aliases.tmpl` and
  `dot_agents/skills/feedback-memory/feedback.log`. Do not alter, stage, or
  commit them.
- Current-session records: this plan and
  `docs/postmortem/2026-08-19-skill-import-environment-inspection.md`.
- A one-time working install exists under `~/.codex/skills/`,
  `~/.agents/skills/`, and `~/.codex/plugins/higgsfield/`. The temporary
  copies added below `dot_codex/` and `dot_agents/` must be replaced with
  declarative externals before delivery so the repository does not carry
  mutable third-party mirrors.
- Existing Superpowers sync demonstrates the required patterns:
  external configuration, a `--dry-run` helper, a hardened systemd setup
  script, 05:00 `Persistent=true` timer units, source/install validation, and
  executable regression tests.

## Approved architecture and decisions

- Manage the official repositories as chezmoi `git-repo` externals below
  `~/.codex/skills/upstreams/`; use managed `symlink_` files for the exact
  Codex skill directories. This preserves supporting files while allowing
  daily fast-forward pulls.
- Manage Higgsfield as an external at `~/.codex/plugins/higgsfield`.
  Its plugin refreshes daily; the installed CLI remains pinned until the user
  explicitly upgrades it and completes OAuth.
- UI/UX Pro Max is generated by its official CLI rather than shipped as a
  repository tree. A managed helper runs its official global update command
  after the external refresh. The same helper provides first-install behavior
  on another PC. The helper does not use `--force` and fails before replacing
  a path that is not an expected skill directory.
- A `design-skills-sync.service` invokes `sync-design-skills`; its
  `design-skills-sync.timer` runs daily at 05:00 with `Persistent=true`.
  Timer setup follows the existing hardened Superpowers setup implementation
  rather than copying unvalidated shell activation logic.
- No paid or authenticated workflow is automatic. 21st operations and
  Higgsfield media requests still require the user’s own credentials and
  explicit request.

## Files and responsibilities

- `.chezmoiexternal.toml.tmpl`: declarative git-repo externals with 24-hour
  refresh periods.
- `dot_codex/skills/symlink_*.tmpl`: exact visible Codex skill links to the
  cloned upstream directories.
- `.chezmoiexternal.toml.tmpl`: declares the Higgsfield plugin target; chezmoi
  creates its parent directory when applying the external.
- `scripts/executable_sync-design-skills`: targeted manual/daily refresh
  with `--dry-run`; the only component allowed to run the UI/UX Pro Max
  updater.
- `scripts/executable_setup-design-skills-timer`: validates, enables, and
  disables the exact managed helper and systemd units.
- `dot_config/systemd/user/design-skills-sync.{service,timer}`: user-scoped
  daily schedule.
- `tests/test_design_skills_sync.py`: regression tests for helper arguments,
  unit contents, setup validation, and failure sanitization.
- `README.md`, `dot_agents/skills/README.md`, and
  `docs/smoke-tests.md`: user-facing setup, availability, and manual
  verification.
- `docs/postmortem/2026-08-19-skill-import-environment-inspection.md`: all
  unexpected sandbox/patch-helper failures and their final resolution.

## Risks, edge cases, and rollback

- Upstream changes can be breaking or removed. Git pulls use fast-forward-only
  behavior; the last checked-out upstream revision remains recoverable in each
  local clone. Rollback is disabling the timer and resetting the affected
  external clone to a known revision.
- On a new host, Node/npm is required for UI/UX Pro Max. The helper must emit
  an actionable failure rather than leaving a partial install.
- Symlink targets must be relative to `~/.codex/skills/`, must resolve after
  clone, and must never overwrite a non-symlink target.
- A failed refresh must not enable a timer, trigger OAuth, or conceal an
  upstream error. The systemd journal carries sanitised diagnostics.
- Removing current-session vendored directories is authorized by the user’s
  approval of the managed-external design. Do not delete any path outside the
  explicitly listed current-session directories.
