# Private Vault Placeholder

This directory marks where the optional Second Brain workflow integrates with a
local knowledge vault. The public repository includes the command and skill
implementation, but deliberately excludes personal notes, raw session captures,
attachments, reminders, and migration ledgers.

Keep the real vault outside Git or in a separate private repository. Configure
the local path using the Second Brain operator guide, run its privacy checks, and
only commit deliberately authored public examples.
