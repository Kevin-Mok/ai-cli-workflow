# Select a maintained metaprompt skill

Choose the best-supported default metaprompt skill for example-user using concrete
source evidence and a fair Codex benchmark. Audit actual native skills in
GitHub repositories with at least 1,000 stars; report exact counts and timestamps,
licenses, archive state, pinned revisions, and skill-level maintenance diffs.
Require create, sharpen, reusable-template and coding-agent workflows and a
substantive post-introduction change within 180 days. Exclude copied lineages,
imports, moves, formatting and unrelated repository activity from maintenance.

Select at most five eligible independent finalists before model outputs. Compare
them with raw-request and fixed minimal-contract controls on fresh synthetic
cases grounded in real task patterns. Use `gpt-6.1-sol`, medium reasoning through
the configured Codex subscription for compiler and downstream solver. Execute
at most 100 complete trial attempts, initially including two development trials
per arm. The pre-freeze calibration round uses the ten spare attempts: four
development trials and sixteen held-out trials per arm, with equal scored
trials across four equally weighted workflows.
Limit every trial to 10 compiler and 10 solver requests; never exceed 2,000
inference requests overall. Failed requests, tools and clarification turns count.

Prove the actual tool workflow offline before spending quota. Supply manifests
up front, allow the skill's native authoring and refinement stages, isolate every
trial, and keep hidden scoring keys out of model context. Resolve infrastructure
faults during development. Freeze candidates, fixtures, scoring, schedule and
settings before held-out execution. Use objective schema, source and executable
checks, not unmetered model judges. Retain sanitized traces and request-level
usage, including aborted episodes.

Recommend a specific eligible skill from balanced task success and native
completion; exclude serious authorization violations. Break exact ties by
substantive maintenance, lower first-use cost, then repository stars. Explain
what the evidence proves, whether raw/minimal controls justify the extra cost,
and where uncertainty remains. Do not finish with only an inconclusive table.

Deliver the reproducible harness, pinned sources and receipts, raw results,
recommendation report, tested installation/rollback instructions, README and
smoke-test updates, and a current ExecPlan. Preserve the previous pilot unchanged.
Do not install skills, change defaults, create worktrees, commit or push.
