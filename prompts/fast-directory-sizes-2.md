User context
`du -d 1` still scans the entire descendant tree, and piping it to `sort` delays results until that scan finishes. `--apparent-size` measures logical bytes and can overstate disk usage for sparse files. Improve practical time to useful results and, where demonstrated, total scan time. Do not promise that a display-depth limit avoids traversal or that an exact uncached directory total can skip reading descendant metadata.
