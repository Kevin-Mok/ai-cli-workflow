# Vetted Skill Precedents

Compare each new skill or standing rule with its 2–3 closest entries before
recording an admission verdict. IDs are stable; the name follows the colon. Search names, descriptions and jobs
for overlap before scoring; a duplicate should merge or receive DENY.
The tables retain the audited roster; the inventory block records current source
states. An approved ADD is not proof that private-branch intake has landed.

## Patterns

- Keep distinct jobs with observed use or follow-through; separate commit scopes,
  preference capture, bug lessons, prompt authoring and prompt execution.
- Cull unused variants covered by an effective umbrella. Large bodies with rare
  loads lose; broad frontend and README triggers need narrowing after misfires.
- Merge useful behavior into a named survivor. Replace an umbrella in the same
  slot when its short trigger preserves coverage; do not count that as a new job.
- Admit complementary tools only with evidence and a bounded body. Component
  rules belong in on-demand references. A high ratio cannot rescue zero value
  or duplicate coverage; an explicit user override stays visible as an exception.

## Basis and notation

Source: the user-supplied relevance audit, 2026-10-22. These are supplied estimates,
not current measurements or fresh private-branch inspections. Cost tok =
description chars/4 + body bytes/40; score = (2 × value + uniqueness)/(cost/100).
The 10% body-load assumption is unmeasured. Rounded source costs/scores are retained;
measure UTF-8 bytes and both full token costs afresh for an actual admission.
Value ranges 0–5; uniqueness ranges 0–2. Normal cutoff: value ≥2, uniqueness ≥1,
score ≥1. `last30days` is the explicit user-approved exception.

L = 60-day filtered loads, F = followed, M = misfires, X = explicit invocations,
R = lifetime reads. The existing-skill study covered 1011 filtered sessions;
PR reads use a separate all-cwd scan and may include candidate test runs. Followed
and misfire counts are heuristic; unreported counts are unknown, not zero.
Explicit invocation may inject a body without a file read. Counts, role categories
and reasons below are sanitized aggregates, without raw session examples.
